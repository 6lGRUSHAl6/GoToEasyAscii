# ASCII-генератор - документация

Консольная утилита для преобразования изображений в ASCII-арт с поддержкой цветного вывода, автоопределения фона терминала и многопоточной обработки.

Поддерживаемые форматы: **JPEG**, **PNG**.

---

## Быстрый старт

Запуск без компиляции:

```bash
go run ascii.go [flags] <путь_к_изображению>
```

Или сначала собрать бинарник, а потом запускать его:

```bash
go build -o ascii ascii.go
./ascii [flags] <путь_к_изображению>
```

---

##  Флаги командной строки

| Флаг | Тип | По умолчанию | Описание |
|------|-----|---------------|----------|
| `-color` | `bool` | `false` | Включает цветной вывод с использованием ANSI-escape последовательностей |
| `-light` | `bool` | `false` | Принудительно использует рампу символов для **светлого** фона терминала |
| `-dark` | `bool` | `false` | Принудительно использует рампу символов для **тёмного** фона терминала |
| `-width` | `int` | `100` | Ширина выходного ASCII-арта в символах (высота вычисляется автоматически с учётом соотношения сторон) |
| `-workers` | `int` | `runtime.NumCPU()` | Количество параллельных воркеров для обработки строк изображения |

>  **Важно:** если указаны сразу `-light` и `-dark`, приоритет отдаётся `-dark` — он переопределяет `-light`.

---

## Автоопределение фона через `COLORFGBG`

Если флаги `-light` / `-dark` не заданы явно, программа пытается определить фон терминала по переменной окружения `COLORFGBG` (её устанавливают многие терминалы, например xterm, urxvt):

- если последняя цифра значения — `7` или больше `9`, фон считается **светлым**, и используется `lightBgRamp`;
- во всех остальных случаях (в том числе если переменная не задана) используется `darkBgRamp` — тёмный фон.

---

## Рампа символов

Используется классическая **рампа Пола Бурка** — 70 символов, упорядоченных от светлых к тёмным:

```
 .'`^",:;Il!i><~+_-?][}{1)(|\/tfjrxnuvczXYUJCLQ0OZmwqpdbkhao*#MW&8%B@$
```

- **Тёмный фон** — прямой порядок: тёмные пиксели → пробел, светлые → плотные символы.
- **Светлый фон** — инвертированный порядок: тёмные пиксели → плотные символы.

---

## Примеры использования

**1. Базовый вывод** (ч/б, тёмный фон, ширина по умолчанию — 100)

```bash
go run ascii.go photo.jpg
```

**2. Цветной вывод на тёмном фоне**

```bash
go run ascii.go -color photo.jpg
```

**3. Принудительно светлый фон, без цвета**

```bash
go run ascii.go -light photo.png
```

**4. Цветной вывод, ширина 70, 4 воркера**

```bash
go run ascii.go -color -width 70 -workers 4 screenshot.png
```

**5. Запуск скомпилированного бинарника**

```bash
go build -o ascii ascii.go
./ascii -color -width 120 image.jpeg
```

## Советы по производительности

- Для больших изображений увеличивайте число воркеров через `-workers` (по умолчанию — число ядер CPU).
- Цветной режим (`-color`) увеличивает объём вывода и требует больше ресурсов на обработку.
- Подбирайте `-width` под содержимое изображения — от этого сильно зависит визуальное качество результата.

---

## Обработка ошибок

- Если файл не найден или формат не поддерживается — программа выводит сообщение об ошибке и завершает работу.
- Ошибки записи в stdout (например, при перенаправлении вывода в файл) также обрабатываются корректно.
